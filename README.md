# Boss直聘一键智能投递助手 (Chrome Extension & Web Dashboard)

> 专为 Boss 直聘打造的智能批量求职投递助手。基于 Chrome 扩展 Manifest V3 规范与 React 构建，严格遵循防封控设计与 Ponytail 极简模式。

---

## 🌟 核心特性与优势

1. **零服务端·零账号泄露风险**：
   - 所有逻辑完全运行在本地浏览器，无需向任何第三方服务器提供 Boss 账号密码或 Cookie 凭据。
2. **复用原生登录态与设备指纹（防封核心）**：
   - 直接运行在日常使用的 Chrome/Edge 浏览器环境中，具备真实的浏览器指纹，不触发异地或数据中心 IP 风控。
3. **智能多维筛选与黑名单过滤**：
   - **目标关键词**：设置期望岗位词（如 `前端`、`React`、`全栈`）。
   - **排除词过滤**：自动跳过包含 `外包`、`外派`、`驻场`、`兼职`、`实习生` 等词汇的职位。
   - **企业黑名单**：可自定义过滤特定人力公司、中介或培训机构。
   - **薪资范围过滤**：智能解析 `15-25K`、`20-30K·14薪` 等文本，不符期望自动跳过。
   - **自动去重**：已沟通过的岗位自动跳过，绝不重复打招呼。
4. **模拟真人的拟人化交互防封**：
   - 每次点击“立即沟通”之间引入 **高斯随机延迟（默认 3~7 秒）**。
   - 自动模拟真人平滑滚动屏幕并触发触底翻页。
   - 支持设置单次运行上限（如 20 个）及当日累计保护。
5. **安全验证即时熔断**：
   - 一旦页面出现极验滑块验证码（Geetest）或平台异常拦截，自动化立即暂停并提示人工处理，杜绝死循环导致封号。
6. **双重交互体验**：
   - **扩展控制台（Popup）**：点击浏览器右上角图标呼出配置面板与实时进度。
   - **页面悬浮胶囊**：在 Boss 直聘求职列表页（`zhipin.com/web/geek/job`）右下角自动挂载半透明轻量胶囊，一键启动/暂停与状态查看。
   - **本地 Web 面板**：支持直接本地运行 `pnpm dev` 打开网页预览配置。

## 🚀 快速安装使用指南（只需 1 分钟）

本项目已经完成一键构建，打包产物位于工程根目录下的 `dist` 文件夹中。

### 第 1 步：在浏览器中加载插件

1. 打开 **Chrome** 或 **Edge** 浏览器，在地址栏输入并回车：
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`
2. 打开右上角的 **“开发者模式” (Developer mode)** 开关。
3. 点击左上角的 **“加载已解压的扩展程序” (Load unpacked)** 按钮。
4. 在弹出的文件选择器中，选择本项目的 **`dist`** 文件夹：
   ```
   C:\Users\Administrator\.gemini\antigravity\scratch\boss-auto-apply-extension\dist
   ```
5. 看到列表中出现 **“Boss直聘一键智能投递助手”**，即表示加载成功！建议在浏览器工具栏将插件图标固定（Pin）到右上角。

---

### 第 2 步：登录 Boss 直聘并开始投递

1. 打开浏览器，访问 **[Boss直聘官网](https://www.zhipin.com)** 并登录您的求职账号。
2. 进入职位搜索/推荐列表页面（例如在搜索框输入“前端”，选择目标城市）：
   `https://www.zhipin.com/web/geek/job`
3. 此时即可使用两种方式之一启动：
   - **方式 A（页面右下角悬浮胶囊）**：直接点击页面右下角的 **【🚀 开始投递】** 胶囊按钮。
   - **方式 B（右上角插件图标）**：点击扩展图标，打开控制面板，确认过滤条件后点击 **【一键开始批量投递】**。
4. 助手将全自动：
   - 滚动页面并扫描岗位卡片；
   - 自动比对关键词、薪资、企业黑名单与已沟通状态；
   - 模拟真人点击发起沟通；
   - 随机等待 3~7 秒后处理下一个；
   - 当前页处理完毕后自动平滑滚动触底翻页。

## 💡 防封控与使用建议

1. **单日上限控制**：普通求职者在 Boss 直聘每日打招呼上限约为 100~200 个。建议单次运行批量投递 20~30 个，每天分上午和下午各运行一次。
2. **防封随机间隔**：建议保持默认的 3~7 秒随机等待，切勿将间隔修改为 0 秒或 1 秒的机械化极速模式。
3. **滑块验证应对**：若 Boss 触发了拼图或滑块验证，助手会自动检测并暂停。此时直接在网页上用鼠标完成拼图，再点击插件的【恢复继续】即可。
